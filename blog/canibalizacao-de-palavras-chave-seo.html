Canibalização de palavras-chave: como descobrir páginas do seu site disputando a mesma busca

Alexandre Leite11 de novembro de 2026 · 4 min de leitura

Resposta rápida

Canibalização acontece quando duas ou mais páginas do mesmo site tentam responder à mesma busca e o Google alterna entre elas. Para achar, filtre a consulta no Search Console e veja se várias URLs recebem impressões. Depois, escolha uma página principal: una o conteúdo e redirecione a outra, ou diferencie a intenção de cada uma e ajuste os links internos.

Um sinal comum de canibalização é uma consulta que sobe e desce sem motivo aparente. Num dia aparece um artigo do blog, no outro uma página de serviço, depois um artigo antigo sobre o mesmo assunto. O Google não sabe qual página do seu site é a melhor resposta, e nenhuma delas se firma.

Isso costuma acontecer em sites que publicam há anos sem um mapa de temas. Cada pessoa escreve sobre o assunto do mês, e com o tempo surgem três ou quatro textos parecidos. Abaixo está como encontro e resolvo esses casos.

O que é canibalização de palavras-chave?

É quando páginas do mesmo site competem pela mesma busca e pela mesma intenção. O problema não é ter duas páginas que mencionam o mesmo termo. É ter duas páginas que tentam entregar a mesma resposta para a mesma pessoa.

Uma página sobre "o que é CRM" e outra sobre "como escolher um CRM para imobiliária" podem conviver bem, porque atendem momentos diferentes. Dois artigos chamados "guia de CRM" e "tudo sobre CRM" provavelmente não.

Como descobrir se está acontecendo?

O jeito mais direto é o relatório de desempenho do Google Search Console:

  1. Filtre pela consulta que você quer analisar (ou use "consulta contém" para pegar variações).
  2. Abra a aba de páginas.
  3. Se duas ou mais URLs recebem impressões relevantes para essa consulta, anote.
  4. Mude o período para os últimos 3 a 6 meses e veja se as páginas se revezam nas posições.

Outra checagem rápida: pesquise no Google site:seudominio.com.br seguido do assunto. Se aparecem várias páginas com títulos quase iguais, vale abrir uma por uma.

Várias páginas com impressões para a mesma busca não são problema por si só. Vira problema quando elas se revezam e nenhuma ganha força.

Como decidir o que fazer com cada página?

SituaçãoO que fazer
Duas páginas respondem a mesma coisa e uma é claramente melhorUnir o que houver de útil na melhor e redirecionar a outra com 301
As páginas parecem iguais, mas poderiam atender intenções diferentesReescrever títulos, introdução e foco de cada uma para separar as intenções
Uma página de serviço disputa com um artigo do blogFazer o artigo apontar para a página de serviço e tirar do artigo a promessa comercial

Para escolher a página principal, olho quatro coisas: qual recebe mais cliques na consulta, qual tem mais links de outros sites, qual está mais alinhada ao que o Google mostra na primeira página e qual é mais importante para o negócio.

Como unir duas páginas sem perder tráfego?

  • Leve o conteúdo útil: exemplos, dados e perguntas que só existiam na página que vai sair.
  • Redirecione com 301: a URL antiga deve levar direto para a principal, sem passar por outros redirecionamentos.
  • Atualize os links internos: troque os links que apontavam para a página antiga. Não dependa só do redirecionamento.
  • Tire a URL antiga do sitemap.
  • Acompanhe por algumas semanas: compare cliques e posição da consulta principal antes e depois.

E os links internos, onde entram?

Os links internos dizem ao Google qual página é a referência do assunto. Se o seu menu, a home e vários artigos apontam para páginas diferentes usando o mesmo texto âncora, você reforça a confusão. Escolha a página principal e faça os textos relacionados apontarem para ela com âncoras que descrevam o tema.

Canibalização afeta a presença em respostas de IA?

Pode afetar de forma indireta. Ferramentas de IA que buscam na web tendem a citar páginas claras e completas sobre um assunto. Quando o conteúdo está espalhado em várias páginas rasas, nenhuma delas se destaca como fonte. Uma página principal bem organizada, com a resposta direta no início, tem mais chance de ser usada.

Como evitar que volte a acontecer?

Mantenha uma planilha simples com cada página, a busca principal que ela atende e a intenção. Antes de escrever um texto novo, procure a busca nessa lista. Se já existe uma página para ela, o trabalho provavelmente é atualizar a página existente, não criar outra.

Perguntas frequentes

Duas páginas aparecendo para a mesma busca é sempre canibalização?

Não. Se cada página atende uma intenção diferente e as duas se mantêm estáveis, pode até ser positivo. É canibalização quando elas se revezam e nenhuma se firma.

Posso usar canonical em vez de redirecionar?

O canonical é uma sugestão para o Google e faz sentido quando as duas páginas precisam continuar existindo para o usuário. Se uma delas não precisa mais existir, o redirecionamento 301 é mais claro.

Quanto tempo leva para ver resultado depois de unir páginas?

Depende da frequência com que o Google rastreia o site. Em geral, vale acompanhar algumas semanas, comparando o mesmo período antes e depois na consulta principal.

Preciso de ferramenta paga para encontrar canibalização?

Não. O Google Search Console e a pesquisa site: no Google já resolvem a maioria dos casos. Ferramentas pagas ajudam em sites muito grandes.
